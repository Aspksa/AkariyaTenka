# «Перенос Akariya» — безопасная панель переноса

В панели доступны четыре действия: **На SSD**, **На компьютер**, **Сравнить**, **Восстановить**.

Укажите исходную и целевую папки. При восстановлении также требуется идентификатор ранее созданного backup; для создания новой копии на ПК отметьте, что целевая папка отсутствует. Панель формирует команду PowerShell и позволяет её скопировать. Она НЕ выполняет запись из работающего веб-интерфейса: сначала закройте Akariya и все другие процессы, которые могут менять файлы.

- На SSD — безопасный план `portable-replace.mjs plan`; просмотр результата обязателен перед `apply` в отдельной оболочке.
- На компьютер — план переноса изменённых файлов либо перенос в отсутствующую папку через `portable-transfer.mjs copy`.
- Сравнить — анализ общего снимка и конфликтов через `portable-state.mjs compare`.
- Восстановить — проверенное восстановление в новую папку через `portable-restore.mjs restore`, без перезаписи исходной установки.

Запускайте команды из корневой папки Akariya с Node.js 20+. Старые базы SQLite нельзя объединять простой перезаписью. Для SSD требуется остановка приложения. При ошибке синхронизации не очищайте блокировки автоматически, сначала разберитесь с состоянием обоих экземпляров.
