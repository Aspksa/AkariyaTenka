# Настройка ключей двойным щелчком

После обновления проекта из `main` откройте папку Akariya Tenka и запустите `AKARIYA-KEYS.bat`.

- Ключи в `C:\AkariyaPublisherKeys` будут найдены автоматически.
- Если их там нет, скрипт запросит полный путь к папке с тремя файлами издателя.
- При отсутствии portable Node.js `AKARIYA-KEYS.bat` загрузит официальный Node.js штатным скриптом `scripts/bootstrap-node.ps1` с проверкой SHA-256. Администратор и глобальный PATH не нужны.
- Локальный импорт проверяет Ed25519 и отпечаток, запрашивает пароль дважды (не менее 8 символов) и создаёт `keys/private/signing-vault.enc`, `keys/public/publisher-public.pem` и `keys/public/publisher-spki-sha256.txt`.
- Пароль не передаётся аргументом, исходные ключи не удаляются, существующие файлы не перезаписываются, `keys/private/` исключён из Git.
- Настройка не включает автоматические обновления или доверие к неутверждённому публичному ключу.

Для ключа подписи обновлений рекомендуем использовать уникальный пароль значительно длиннее 8 символов: короткий пароль легче подобрать при краже контейнера.

При неуспешном запуске проверьте, что папка содержит все три ранее созданных файла и нет уже установленного `keys/private/signing-vault.enc`. Незашифрованный исходный ключ сохраняйте вне репозитория до отдельной проверки резервной копии.
