# Akariya Tenka — Crimson Fox visual system

Основа визуального направления — изображения восьмихвостой лисы, выбранные владельцем проекта. Тема использует тёмные графитовые и бордовые поверхности, алый оттенок пламени и сдержанные золотые детали. Исходные изображения пользователя **не** размещаются в репозитории: вместо них разработана отдельная векторная эмблема, не требующая больших внешних ассетов.

## Токены

| Token | Color | Purpose |

| Void | `#080709` | фоновый цвет |
| Surface | `#170e13` | фоновая поверхность |

| Ember | `#f45b54` | дополнительный акцент |
| Gold | `#ddb477` | декоративный акцент |
| Muted | `#c3adb0` | второстепенный текст |

Логотип: `apps/web/public/akariya-fox.svg`. Кнопки и диагностические панели сохраняют собственные события и динамические импорты; изменение является визуальным, не затрагивает серверное состояние, систему обновлений или хранение ключей.

## Качество и доступность

- Мобильная адаптация для viewport от 320 px.
- `focus-visible` для клавиатурной навигации.
- `prefers-reduced-motion` учитывается.
- Подписаны декоративный фон (`aria-hidden`) и логотип (`alt`).
- Пользовательские действия, связанные с переносом, сохраняют прежнее подтверждение.
- Шрифты поставляются вместе с приложением (без обращения к сети): **Onest** — основной текст, **Unbounded** — заголовки и крупные числа, **JetBrains Mono** — хеши, пути и подписи графиков. Браузер загружает только нужные поднаборы (кириллица/латиница) по `unicode-range`.

## Обновления и аналитика проекта

Страница «Обновления GitHub» состоит из карточки статуса с анимированным индикатором состояния (проверка, доступно, актуально, ошибка, установка), блока «Что нового», резервных копий, ленты истории обновлений и раздела **Akariya Insights** (`apps/web/src/features/project-insights.ts`):

- Вся аналитика собрана на одной странице без вкладок: KPI с мини-гистограммами, затем главы «История проекта», «Код под микроскопом», «Рекорды и редкости», «Измерения обновлений» на общей 12-колоночной сетке.
- Графики: недельная гистограмма с плавной линией тренда, радиальные «часы активности», карта активности за 26 недель, гистограмма дней недели, горизонтальные гистограммы (слова, языки, конструкции кода, размеры файлов), кольцевая диаграмма состава строк, шкалы здоровья обновлений.
- Компактные плитки: подпись сверху, пояснение под ней, значение — справа снизу; процентные значения получают мини-кольцо, сравнимые счётчики — полоску-измеритель снизу. Неизмеряемые показатели собраны в строку чипов «Пока не измеряется».
- Каждая плитка получает собственный оттенок `--hue`; иконки — векторные (`components/icons.ts`), значения анимируются счётчиком, плитки появляются при прокрутке. При `prefers-reduced-motion` всё отображается сразу без анимаций.
- Значения не выдумываются: все мини-графики строятся только из реальных данных.
